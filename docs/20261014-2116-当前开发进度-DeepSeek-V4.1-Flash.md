## 当前功能清单（均已验证）

- 插入 NTFS 盘 5~10 秒自动挂载为读写（守护进程 root 轮询 3s）
- **插入 BitLocker 加密盘：标记为 `locked` 并跳过自动挂载（绝不猜密码）；菜单栏提供三种解锁入口 —— 用密码 / 用 48 位恢复密码 / 用 .BEK 恢复密钥文件，解锁后读写挂载**
- **钥匙串按方法记住 BitLocker 凭据（用户密码 / 恢复密码 / .BEK 路径），下次插入按原方法自动解锁；可「忘记已保存的凭据」**
- **重新锁定 BitLocker**（卸载解密卷 + 停止 dislocker-fuse）
- 菜单栏 App：显示盘与 RW/RO/🔒 状态、挂载/卸载/安全弹出/Finder 打开、打开日志、重新扫描
- 命令行 ntfsctl：list/mount/unmount/eject + **unlock（四种凭据）/lock** +
  **诊断三件套 `info [-v]`（读元数据）/ `dump`（导原始元数据）/ `unlock --verbose`（dislocker 调试日志）**
- FSKit 只读寄生虫持续清理；手动弹出后 60s 不自动重挂（eject marker）
- 挂载互斥锁：防守护进程与手动操作并发叠加挂载
- 中文/空格卷标完整支持；挂载属主解析为 GUI 用户
- 全程无授权框（sudo 免密白名单 + 无内核扩展）

## 最新里程碑（v0.0.12 / v0.0.13，2026-10-14 深夜）

- **修复「记住密码」完全失效**（用户报告）：三个叠加根因
  ① `security` 会把含「非可打印 ASCII」的钥匙串值存成十六进制文本，而旧格式 `凭据\n方法码` 必然含换行 →
  每条凭据都被 hex 化（读回当密码用必然失败）；
  ② 钥匙串用**会变的设备名**（`diskXsY`）做键 → 改用**卷 GUID**（卷头明文可读、跨插拔稳定）；
  ③ `autoTried` 在读取凭据**之前**就写入 → 首插未记住密码的盘被永久标记为已尝试。
  另新增 App 运行日志 `~/Library/Logs/NTFSFormac/app.log`（不记凭据明文）。
- **新增挂载前 NTFS 签名预检**：消除非 NTFS 分区 `ntfs-3g` 失败刷屏（守护日志曾累积 2273+ 行）；
  铁律是**读到空必须 fail-open 继续挂载**，否则被 FSKit 只读挂载的卷因 EBUSY 读不到签名会被误跳过。
- **修复 `lock` 未持互斥锁**（验证中发现的假成功）：`bl_lock_one` 纳入 `lock_mount`，
  消除「解锁报成功、随即回退 locked」。
- 版本号入口：`ntfsctl list --porcelain` 现为
  `device|label|<ntfs|bitlocker>|mountpoint|<rw|ro|none|locked>|guid`
