## 当前功能清单（均已验证）

- 插入 NTFS 盘 5~10 秒自动挂载为读写（守护进程 root 轮询 3s）
- **插入 BitLocker 加密盘：标记为 `locked` 并跳过自动挂载（绝不猜密码）；菜单栏提供三种解锁入口 —— 用密码 / 用 48 位恢复密码 / 用 .BEK 恢复密钥文件，解锁后读写挂载**
- **钥匙串按方法记住 BitLocker 凭据（用户密码 / 恢复密码 / .BEK 路径），下次插入按原方法自动解锁；可「忘记已保存的凭据」**
- **重新锁定 BitLocker**（卸载解密卷 + 停止 dislocker-fuse）
- 菜单栏 App：显示盘与 RW/RO/🔒 状态、挂载/卸载/安全弹出/Finder 打开、打开日志、重新扫描
- 命令行 ntfsctl：list/mount/unmount/eject + **unlock（四种凭据）/lock** +
  **诊断三件套 `info [-v]`（读元数据）/ `dump`（导原始元数据）/ `unlock --verbose`（dislocker 调试日志）**
- FSKit 只读寄生虫持续清理；手动弹出后 60s 不自动重挂（eject marker）
- 挂载互斥锁：防守护进程与手动操作并发叠加挂载
- 中文/空格卷标完整支持；挂载属主解析为 GUI 用户
- 全程无授权框（sudo 免密白名单 + 无内核扩展）

## 未完成 / 已知缺口

- **真实 U 盘（disk4s1）上"成功解锁"尚未执行** —— 该盘的 dislocker 解析缺陷已修复（v0.0.10），
  元数据可完整读取（含 FVEK 与 VIRTUALIZATION INFO）；但用密码 `9999999` 时在 AES-CCM 的 MAC 校验
  处失败（`MAC check failed` → `Unable to get the VMK (0x800c0006)`），说明**凭据不匹配**。
  需该盘真实密码 / 48 位恢复密码 / .BEK 才能完成最后一步压测
