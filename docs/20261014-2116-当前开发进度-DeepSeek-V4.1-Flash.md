## 当前功能清单（均已验证）

- 插入 NTFS 盘 5~10 秒自动挂载为读写（守护进程 root 轮询 3s）
- **插入 BitLocker 加密盘：标记为 `locked` 并跳过自动挂载（绝不猜密码）；菜单栏点「解锁 BitLocker…」输入密码后读写挂载**
- **钥匙串记住 BitLocker 密码，下次插入自动解锁；可「忘记已保存的密码」**
- **重新锁定 BitLocker**（卸载解密卷 + 停止 dislocker-fuse）
- 菜单栏 App：显示盘与 RW/RO/🔒 状态、挂载/卸载/安全弹出/Finder 打开、打开日志、重新扫描
- 命令行 ntfsctl：list/mount/unmount/eject + **unlock/lock**
- FSKit 只读寄生虫持续清理；手动弹出后 60s 不自动重挂（eject marker）
- 挂载互斥锁：防守护进程与手动操作并发叠加挂载
- 中文/空格卷标完整支持；挂载属主解析为 GUI 用户
- 全程无授权框（sudo 免密白名单 + 无内核扩展）
