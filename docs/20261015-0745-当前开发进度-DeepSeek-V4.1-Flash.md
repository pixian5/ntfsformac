## 本轮完成（v0.0.14 → v0.0.15）

1. **其它分区检测 + 只读裸镜像挂载**：外置盘上非 NTFS/BitLocker 的 FAT 家族分区（如 Ventoy 的 VTOYEFI，分区类型 0xEF 被 macOS 拒绝识别）现在能被 `list` 列出、可经 `ntfsctl mount <dev>` 只读浏览（dd 导出 → 免分区表镜像附加），`unmount`/`eject` 全闭环清理。详见 `docs/20261015-0745-其它分区检测与只读镜像挂载-DeepSeek-V4.1-Flash.md`。
2. **根除 Touch ID 指纹弹窗**：ntfsctl 的 `as_root` 从交互式 sudo 改为非交互（`sudo -n`）；新增「裸跑免密重入」（非 root 运行安装版时自动以白名单身份重新调用自身）。实测 list/mount/unmount 全链路零弹窗。
3. **App 菜单支持「其它分区」**：显示文件系统类型与「只读副本」语义说明，提供「只读挂载（浏览副本）」。
4. **守护进程过滤其它分区**：daemon 不自动挂其它分区（避免 EFI 分区被自动挂出来当噪音），只由用户显式挂载。
5. **新增 test-other-fs.sh（11/0）**，全量回归 5 套合计 63/0。
6. 清理旧盘拔插残留（僵尸镜像 disk24、孤儿 dislocker 进程、I/O 错误挂载点）。
