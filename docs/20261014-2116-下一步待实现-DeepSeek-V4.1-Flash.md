## P0（近期建议，价值最高）

### 1. 真实 U 盘 BitLocker 成功解锁压测（当前唯一未完成项）
- **现状（v0.0.10 已推进）**：真实 U 盘（disk4s1）此前卡在 dislocker 的**元数据解析缺陷**
  （未知 value_type 的 datum 中断遍历 → 读不到 FVEK / VIRTUALIZATION INFO → `Unable to compute regions`），
  **该缺陷已修复**：现在能完整解析元数据，错误已收敛到「凭据层」
  （密码 `9999999` 在 AES-CCM 的 MAC 校验失败）。加密**镜像**盘端到端 29 项全绿。
- **阻塞**：缺该盘**真实凭据**（用户密码 / 48 位恢复密码 / .BEK）。
- **方案**：拿到凭据后跑
  `sudo bash test/test-bitlocker.sh --device disk4s1 --password-file /path/pw`
  （或 `--recovery` / `--bek`），校验大文件写入、热插拔、断电恢复、断连重挂。
  排查时用 `ntfsctl unlock disk4s1 --password 密码 --verbose` 看 dislocker 选了哪个 VMK。
- **价值**：发现镜像盘测不出的问题（USB 层、供电、缓存刷盘时机）。

### 2. pkg 安装器（一键安装）
- **现状**：需手动依次运行 install-driver.sh、build-app.sh，还要手动做 FDA / 网络宗卷授权。
- **方案**：`pkgbuild` + `productbuild` 打包：装驱动（含 dislocker 构建产物）→ 装服务 → 装 App → 首次启动引导授权。
- **价值**：从"给开发者的脚本"变成"给普通用户的产品"。

### 3. 卸载脚本 scripts/uninstall.sh
- **方案**：停守护进程 → 删 plist/二进制/库（含 dislocker、libdislocker）→ 卸 FUSE-T（可选）→ 清 marker 与容器目录。
- **价值**：用户可彻底干净移除，反向验证安装完整性。
