# 下一步待实现（2026-10-14 21:16）

> 版本：0.0.8 ｜ 模型：DeepSeek-V4.1-Flash ｜ 承接 docs/20261014-2116-当前开发进度-DeepSeek-V4.1-Flash.md

## P0（近期建议，价值最高）

### 1. 物理 BitLocker 盘压测
- **现状**：BitLocker 全流程已用真实加密**镜像**盘验证（29 项全绿），但物理 U 盘/移动硬盘未测。
- **方案**：用 Windows 对一块 U 盘启用 BitLocker（含 UTF-16 卷标、中文路径），在 macOS 上跑
  `sudo bash test/test-bitlocker.sh --device diskXsY --password '密码'`，校验大文件、热插拔、断电恢复。
- **价值**：发现镜像盘测不出的问题（USB 层、供电、缓存刷盘时机）。

### 2. pkg 安装器（一键安装）
- **现状**：需手动依次运行 install-driver.sh、build-app.sh，还要手动做 FDA / 网络宗卷授权。
- **方案**：`pkgbuild` + `productbuild` 打包：装驱动（含 dislocker 构建产物）→ 装服务 → 装 App → 首次启动引导授权。
- **价值**：从"给开发者的脚本"变成"给普通用户的产品"。

### 3. 卸载脚本 scripts/uninstall.sh
- **方案**：停守护进程 → 删 plist/二进制/库（含 dislocker、libdislocker）→ 卸 FUSE-T（可选）→ 清 marker 与容器目录。
- **价值**：用户可彻底干净移除，反向验证安装完整性。

## P1（体验提升）

### 4. 开机自启
- **方案**：SMAppService（macOS 13+ 官方 API，无需登录项权限），build-app.sh 里注册。

### 5. 挂载/弹出事件通知
- **方案**：UNUserNotificationCenter 在自动挂载/弹出/解锁时发通知。

### 6. 菜单栏图标状态化
- **方案**：按"有盘 rw / 有盘未挂 / 有盘加密未解锁 / 无盘"切换图标（`lock.fill` 已用于 locked）。

### 7. 拔盘残留自动清理
- **方案**：守护进程巡检时若设备节点消失但容器/挂载点残留，自动清理（覆盖意外拔盘，含 BitLocker 容器）。

## P2（工程加固 / 优化）

### 8. BitLocker 恢复密码 / BEK 图形入口
- **现状**：CLI 已支持 `--bek` / 恢复密码 / clearkey，但 App 只有用户密码输入框。
- **方案**：App 增加「用恢复密码解锁」「选择 .BEK 文件解锁」入口。

### 9. 挂载参数调优
- **方案**：对照 macos-fuse-t 支持的选项试验 `big_writes`、`buffer_size` 等，建立基准后固定参数（BitLocker 双层 FUSE 更需调优）。

### 10. 驱动版本检查与升级
- **方案**：App 启动时比对 FUSE-T / ntfs-3g / dislocker 版本，提供一键重装（复用 install-driver.sh）。

## 与既有要求的冲突提示

- **#2 pkg 安装器** 会引入 `pkgbuild`/`productbuild` 构建链，与当前轻量 shell 构建并存，安装流程从"跑脚本"变为"装 pkg"，**需你确认接受**（上轮已表示接受）。
- **sudoers 收敛 vs 零弹窗**：收敛白名单时若某 UI 操作不再被免密覆盖，会重新弹授权框。当前已收敛为
  `ntfsctl` + 固定路径脚本（测试脚本用 `*` 通配），App 日常操作全部走 `ntfsctl`，**零弹窗已验证成立**。
