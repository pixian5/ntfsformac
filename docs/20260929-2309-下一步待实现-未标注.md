# 下一步待实现（2026-09-29 23:09）

> 基于 docs/project-analysis.md 的路线图 + 当前缺口整理，按优先级排序。

## P0（近期建议，价值最高）

### 1. pkg 安装器（一键安装）
- **现状**：需手动依次运行 install-driver.sh、build-app.sh，还要手动做 FDA 授权。
- **方案**：用 `pkgbuild` + `productbuild` 打包：装驱动 → 装服务 → 装 App → 首次启动引导授权（完全磁盘访问 + 网络宗卷）。
- **价值**：从"给开发者的脚本"变成"给普通用户的产品"。

### 2. 物理 U 盘长时间读写压测
- **现状**：逻辑经镜像盘全验证，但真实 USB 盘的耐久性、大文件（>4GB）、多文件并发、热插拔、断电恢复未测。
- **方案**：借一块真 NTFS U 盘，跑：大文件读写 → 目录操作 → 反复热插拔 → eject 后读回校验 → Windows chkdsk 复查。
- **价值**：发现镜像盘测不出的问题（USB 层、供电、缓存刷盘时机）。

### 3. 卸载脚本 scripts/uninstall.sh
- **现状**：driver-install.md 里是手动命令清单。
- **方案**：脚本化：停守护进程 → 删 plist/二进制/库 → 卸 FUSE-T（可选）→ 清 marker 目录。
- **价值**：用户可彻底干净移除，反向验证安装完整性。

## P1（体验提升）

### 4. 开机自启
- **现状**：LSUIElement 但未注册登录项，开机后菜单栏图标不出现（守护进程会工作）。
- **方案**：SMAppService（macOS 13+ 官方 API，无需登录项权限），build-app.sh 里注册。

### 5. 挂载/弹出事件通知
- **方案**：UNUserNotificationCenter 在自动挂载/弹出时发通知；守护进程日志解析或 ntfsctl 加 --notify 回调。

### 6. 图标状态化
- **方案**：按"有盘 rw / 有盘未挂 / 无盘"切换菜单栏图标（systemSymbolName 支持多状态），一眼可见。

### 7. 拔盘残留自动清理
- **方案**：守护进程巡检时若设备节点消失但挂载点残留，自动卸载清空（当前 eject 流程已清，覆盖意外拔盘场景）。

## P2（工程加固 / 优化）

### 8. sudoers 白名单最小化审计
- **现状**：App 走 `sudo -n bash -c <命令>`，免密面较宽。
- **方案**：收敛为 `sudo -n` 仅允许 `/usr/local/bin/ntfsctl` 与 `/sbin/*` 白名单；命令参数校验。
- **注意**：与"无授权框"需求直接相关，收敛时需保证 UI 操作全部仍走免密。

### 9. 挂载参数调优
- **方案**：对照 macos-fuse-t 支持的选项试验 `big_writes`、`compression`、`buffer_size` 等，建立基准后固定参数。

### 10. 驱动版本检查与升级
- **方案**：App 启动时比对 FUSE-T / ntfs-3g 与最新 release；提供一键重装（复用 install-driver.sh）。

## 与既有要求的冲突提示

- **#8 sudoers 收敛** 与"彻底消灭授权框"需求存在张力：收敛后若 UI 某操作不再被免密覆盖，会重新弹授权框。**需你决策**：优先安全最小化，还是优先零弹窗。
- **#1 pkg 安装器** 会引入 `pkgbuild`/`productbuild` 构建链，与当前轻量 shell 构建并存，安装流程从"跑脚本"变为"装 pkg"，**需你确认接受**。
